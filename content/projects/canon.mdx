## SYSTEM OVERVIEW

Canon is a pre-trade risk intelligence layer for onchain agents executing leveraged positions.

Before a trade is sent, an agent can call Canon to evaluate order book depth, liquidation proximity, funding divergence, market impact, value-at-risk, and open interest utilization.

The system returns a structured risk score, recommendation, flags, and detailed metrics that can be used to proceed, reduce size, or abort execution.

## ARCHITECTURE

**Risk Engine**
Combines market microstructure signals into deterministic pre-trade recommendations.

**Market Data Layer**
Maintains fresh in-memory market snapshots and fail-closed signals for stale or missing data.

**Monitoring Logic**
Evaluates live positions against breach classes and produces force-unwind verdicts when conditions degrade.

**Agent Integration**
Provides docs and skill instructions so autonomous systems can validate single trades, batches, and live risk conditions.

## ENGINEERING FOCUS

- Millisecond-grade validation before trade execution
- Clear recommendation semantics for agents
- Freshness-aware market data handling
- Reconciler and monitoring paths for active sessions
- Documentation that agents and humans can both consume

## STATUS

Canon turns risk analysis into a direct execution primitive for agentic trading systems.
